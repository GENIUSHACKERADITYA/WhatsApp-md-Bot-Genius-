INSTALL (ek baar):
  npm install

START:
  npm start

USE:
1. Telegram pe bot kholo
2. /start karo
3. WhatsApp number type karo (jaise 917086852797)
4. Pairing code aayega Telegram pe
5. WhatsApp > Linked Devices > Link with phone number > Code daalo
6. Bot connected!
7. Ab bot ko group mein add karo aur ADMIN do

FEATURES:
✅ Auto Welcome - koi join kare to message
🚫 Anti-Gali - gali dene pe kick
🚫 Anti-Emoji - sirf emoji bheje to kick
👑 Group Safety System

BOT TOKEN CHANGE:
.env file mein TELEGRAM_BOT_TOKEN= ke aage naya token daalo
